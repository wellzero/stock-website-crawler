### B2. ⭐⭐⭐⭐⭐ `43 窄基ETF轮动：年化82.68%，最大回撤13.54%`

**核心逻辑**（小武子 + wywy1995 改编）：

```python
# 14 个窄基 ETF 池：
#   白酒/创新药/中药/新能源车/智能汽车/光伏/通信/AI/计算机/
#   恒生科技/豆粕/华宝油气/黄金/纳指

# 动量因子：年化收益 + R² 综合打分
#   slope = np.polyfit(x, log_y, 1)  # 对数价格斜率
#   annualized_returns = exp(slope)^250 - 1
#   r_squared = ...  # 拟合优度
#   综合分 = 动量 * R²  # 防止趋势假突破
# 每日 9:40 调仓（不是每周）
```

**关键设计**：

- **窄基**（行业/主题 ETF）而非宽基 → 板块暴露更纯
- **对数价格斜率 + R² 双重过滤** → 避免"短期暴涨但趋势差"的假信号
- **跨资产**（A 股+港股+美股+黄金+商品）—— 风险分散
- **日频调仓** —— 动量信号捕捉更及时

**jk2bt 适配度**：100%。

**风险点**：14 个窄基 ETF 里有部分是 2020 年后才上市（如 `159992 创新药`、`560080 中药`），回测期 2015-至今 实际是从 2020 开始算。

**核心打分公式**：

```python
def group_score(df, change_limit, back_days):
    df_ok = df[df['return_' + str(back_days)] > change_limit/100]
    mean = df_ok['return_' + str(back_days)].mean() * 100  # 涨幅均值
    score = int(len(df_ok) / len(df) * mean * 10)          # 占比 × 均值 × 10
    return score
```

- score 500-1000：板块中等热门
- score 100-500：板块弱热门
- score < 100：忽略

### B.4 `89 【复现·水】市场情绪指标专题：行业指数顶部和底部信号.ipynb`

**核心指标**：净新高占比 `(NH-NL)%`

```
净新高占比 = (年度新高个股数 - 年度新低个股数) / 行业内总个股数
取值范围: [-1, +1]
```

**逻辑链**（4 步）：

1. **锚定效应**：创新高股 = 浮盈，抛压小；创新低股 = 浮亏，抛压大
2. **新高新低 = 个股走强走弱最直接刻画**
3. **行业整体强弱 = 行业内个股整体强弱**
4. **归一化（除以总个股数）→ 净新高占比**

**信号判读**（基于中信 28 个一级行业）：

- `(NH-NL)% > 0.5`：行业指数过热 → **顶部信号**
- `(NH-NL)% < -0.5`：行业指数过冷 → **底部信号**
- 简单反转策略：顶部卖出、底部买入

**作者结论**：

> "对科技板块的电子、通信、计算机和传媒行业的逐一复盘……净新高占比（(NH-NL)%）指标能较好地提示行业指数的顶部和底部；简单反转策略有效，**且 2020 年以来策略在科技板块的表现较好**。考虑到反转策略资金占用时间较少，因此比较适合作为指数增强型策略。"
