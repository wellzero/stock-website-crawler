### 2.1 已知缺口

1. **`jqfactor.get_factor_values` 的聚宽原生因子库**（如 `ARBR`/`SGAI`/`net_profit_to_total_operate_revenue_ttm`）—— 这些是聚宽专有因子集。**挽救方法**：用 `get_fundamentals` 拉底层财务字段 + 自实现公式；或直接用 jk2bt 的 `get_factor_kanban_values`（覆盖 Alpha101/191 + 风险/风格因子）。
2. **`kuanke.user_space_api`（宽客空间）** —— 第三方函数库，需逐个函数移植或绕过。
3. **`follow_brain.csv` 等外部研究产物** —— 韶华系列用了手工标签，需在 jk2bt 的 study 目录下放同名文件。
4. **数据范围**：用 akshare 拉数据，截至 2026-06-27 完整可用；龙虎榜、北向数据在 2017 年前可能不全。
5. **分钟线回测**：jk2bt 的 `attribute_history` 支持 daily 频率，分钟级对部分策略（龙回头/集合竞价）需要更细的 `get_bars` 参数确认。

> **结论**：**90% 的策略可在 jk2bt 本地直接跑回测**；剩下 10% 需补 `jqfactor` 因子或外部文件。

### 4.1 致命性结论

- **A 类（纯小市值）**：原版基本**全部失效**。2024 年 1-2 月微盘股崩盘 + 国九条双重打击，wywy1995/齐涨系列/7 年 40 倍 全部回撤 30%+。**挽救手段**：套用「国九小市值」「国九条后中小板微盘小改」的过滤规则。
- **D 类（打板/龙头）**：未彻底失效，但**胜率与赔率双降**。挽救手段：叠加情绪指数择时 + 严控仓位。
- **C 类（多因子）**：模型本身可用，但**特征/标签需用 2022 年后数据重训**，且财务字段需重映射。
- **B/E/F/G/I/J 类**：与规则无直接关系，**继续有效**。

## 7. 风险提示

1. **国九条后大分化**：2024-04 后小市值/微盘/低价股流动性显著下降，原版小市值策略回撤普遍 30-60%。
2. **印花税上调**：2008/2023 已两次调整，回测假设印花税 0.1% 已不能完全反映未来风险。
3. **过度拟合警示**：聚宽社区"7 年 40 倍""10 年 206 倍" 等数字在样本外往往**衰减到 30% 以下**。本表预期年化已主动下调。
4. **流动性**：年化 100%+ 的小盘策略容量普遍 < 500 万；超过此规模滑点会吞掉一半收益。
5. **数据漂移**：j k2bt 跑回测用的是 akshare 数据，与聚宽 2015-2022 的回测环境数据**口径有差异**。需要至少看 2023-2025 的样本外表现。
6. **机器学习**：所有 ML 策略必须用 2022 年后数据重训，且需要**滚动训练**而非一次性。
7. **本报告不含实盘建议**：所有"预期年化"仅是基于历史回测的经验值，**不代表未来收益**。

## 11. 12 大类核心逻辑精炼

> 一句话定义 + 三句逻辑 + 关键信号 + 挽救建议。
> 一策略可同属多类，但每类核心逻辑独立。

### 11.A 小市值 / 微盘 / 国九条（68 个）

**核心**：在全 A 里筛最小的那一撮股票（一般 20–100 亿），再叠质量/动量过滤，周频换手吃小市值溢价。

**逻辑**：
- 小盘股长期回报 > 大盘股（Size Premium），是 A 股最古老的 alpha 之一。
- 国九条后，叠加"非 ST、归母净利 > 0、营收 > 1 亿、净资产 > 0"等硬过滤，把"差小盘"剔掉。
- 因子合成：质量（ROE/ROA/毛利率）+ 估值（PE/PB）+ 动量（20/60 日）+ 情绪（换手率/资金流），等权或 IC 加权打分。

**关键信号**：市值排名百分位 + 财务硬过滤 + 多因子综合分 + 涨停/停牌过滤。

**挽救建议**：原版基本失效（2024 年 1-2 月微盘崩盘）。**首选 06/08 期国九版本**（4 只持仓 + 银华日利空仓月份），或用 95 只大容量版做分散。

### 11.B ETF 轮动 + RSRS 择时（61 个）

**核心**：在 4–20 只行业/主题 ETF 池里，**持有过去 20 日动量最强的那 1–3 只**，用 RSRS 指标控制仓位进出。

**逻辑**：
- 动量效应：过去 1 个月涨得好的，下个月继续表现好的概率偏高（短期趋势延续）。
- RSRS（阻力支撑相对强度）= 用过去 18 日 high-low 序列拟合斜率，做 z-score。z > 0.7 满仓、< -0.7 空仓。
- 行业 ETF 代替个股：避免踩雷、印花税减半、流动性好、可日内。
- 月度或双周调仓，**容量大、回撤小、跨周期有效**。

**关键信号**：20 日收益率斜率 + RSRS 斜率 z-score + 持仓 ETF 数上限 + 跌破 MA 离场。

**挽救建议**：**完全不需要挽救**。这是 2024–2026 最稳的"底仓三件套"之一，B 类策略可以直接跑出正收益。

### 11.C 多因子 / 机器学习 / AI（35 个）

**核心**：用 5–200 个因子（价值/质量/动量/情绪/技术）打分排序，或用 ML 模型（随机森林/XGBoost/SVR/神经网络/强化学习）预测下期收益，选 top-N 持仓。

**逻辑**：
- 因子有效性：每个因子在历史上对未来收益有解释力（IC > 0.02、RankIC > 0.03 才合格）。
- 多因子合成：等权 / IC 加权 / 最大化 IR 加权 / 最大分化度。
- 机器学习：把多因子当特征，用监督学习预测未来 5/10/20 日收益或排序，再用预测值选股。
- 调仓周期多为周/月，持仓 10–50 只。

**关键信号**：因子 IC/RankIC、分层回测、模型 AUC/IC、换手率、特异度。

**挽救建议**：**因子库需重映射**（聚宽原生因子 → jk2bt 的 `get_factor_kanban_values` + `get_fundamentals` 重算），**模型必须用 2022 年后数据重训**。改完后能跑，但不能再用 2018–2021 的回测数字当预期。

### 11.D 打板 / 龙头 / 涨停 / 首板（34 个）

**核心**：找当下最强题材的龙头股，**涨停/连板/分歧反包** 的瞬间介入，T+1 卖出，吃情绪溢价。

**逻辑**：
- 龙头战法：题材启动时第一个涨停、连板次数最多、成交额最大、分歧转一致（弱转强）。
- 集合竞价判断：开盘量比、竞价涨幅、最后几秒的方向决定开盘瞬间的强弱。
- 技术形态辅助：底分型、早晨十字星、单阳不破、二板反包。
- 分钟级回测，对滑点和流动性极度敏感。

**关键信号**：涨停封单量 + 连板高度 + 龙虎榜游资席位 + 集合竞价量比 + 题材热度。

**挽救建议**：题材驱动型，2024 年后胜率与赔率双降。**低仓位试 + 叠加情绪择时**（RSRS 或市场宽度空仓期不打板），单只不超过组合 5%。

### 11.E 高股息 / 价值 / 红利 / 低波（22 个）

**核心**：找高分红的低估值股票，长期持有吃**股息 + 估值修复**，本质是"现金流折现的极简实现"。

**逻辑**：
- 股息率筛选：TTM 股息率 > 4%，且连续分红 3 年以上（避免"高分红陷阱"）。
- 质量过滤：ROE > 8%、负债率 < 60%、营收稳定、审计意见标准。
- 低波动率：近 60 日波动率排名后 30%（低回撤友好）。
- 季度/半年度再平衡，10–50 只持仓，**回撤极小**。

**关键信号**：TTM 股息率 + ROE + PE/PB/PCF + 60 日波动率 + 分红可持续性。

**挽救建议**：**完全不需要挽救**。是 2024–2026 防御底仓首选。红利搬砖（年化 29%）、高股息低杠杆小市值、漂亮 50、欧奈尔 CANSLIM/RPS 都能直接跑。

### 11.F 可转债 / 双低（2 个 jupyter）

**核心**：买"低价格 + 低转股溢价率"的可转债，**同时吃债底保护和正股强赎博弈**。

**逻辑**：
- 双低公式 = 价格 + 转股溢价率 × 100，排名取前 20–30 只。
- 价格 < 100 元时有债底保护（信用风险可控时），价格 < 110 元 + 溢价率 < 20% 是经典"双低"区。
- 强赎博弈：进入转股期后正股强势，发行人会强赎（按 100 元+利息），转债需跟涨至少 30% 才有"不亏"的安全垫。
- T+0 交易、印花税只收卖出、流动性好。

**关键信号**：转债价格 + 转股溢价率 + 剩余规模 + 强赎进度 + 正股动量。

**挽救建议**：**完全有效，独立大类**。原版 86 期/95 期 jupyter 可直接用 jk2bt 跑。可转债 ETF（如 511380）可作为简化的场内替代。

### 11.G 行业轮动 / 主题 / 概念（4 个）

**核心**：在申万一级行业或主题指数之间，**按景气度/拥挤度/动量打分轮动**，每期持有 3–5 个最强行业。

**逻辑**：
- 景气度：行业利润同比、PMI、产销量数据（最慢、最准）。
- 拥挤度：换手率分位、成交占比、新高比例（顶底信号）。
- 动量：20/60 日涨幅（最简单、最及时）。
- 三类信号合成，择强汰弱，季度调仓权重、年度调行业池。

**关键信号**：行业 ROE 同比 + PMI 分位 + 拥挤度分位 + 行业动量斜率。

**挽救建议**：**跨周期有效**，与个股规则无关。如果想再叠加一层，可以做"行业 ETF + 个股 top-N"双层组合。

### 11.H 趋势 / 形态 / 缠论 / K 线（8 个）

**核心**：识别上升趋势（均线多头、缠论向上笔、形态突破），**右侧交易顺势而为**，跌破趋势线止损。

**逻辑**：
- 趋势定义：价格 > MA20 > MA60 > MA250（多头排列）。
- 缠论：底分型 + 笔向上 + 中枢突破 = 第一类买点。
- 经典形态：早晨十字星（反转）、圆弧底（反转）、双底（N 字）、突破前高（动量）。
- 周/月级别持仓，跌破 MA20 或趋势线即止损。

**关键信号**：均线排列 + 缠论买卖点 + 形态识别（突破量能、振幅）。

**挽救建议**：**通用工具类**，不构成独立策略，**可作为选股器或择时模块叠加**到任何主线策略上。

### 11.I 多资产 / 股债平衡 / 全天候（8 个）

**核心**：股票 + 债券 + 商品 + 海外，**按风险预算（不是市值）分配权重**，桥水全天候为典型。

**逻辑**：
- 风险平价：每个资产对组合波动率贡献相等（不是 60/40 股债）。
- 经济周期四象限：增长/通胀/衰退/滞胀下，调整股债商金比例。
- 低相关性：股/债/金/商品 相关性低，分散效果好。
- 月/季度再平衡，吃**时间复利**和**相关性红利**。

**关键信号**：资产波动率（年化） + 相关性矩阵 + 经济周期指标（PMI/CPI/失业率）。

**挽救建议**：**跨周期最稳的"长钱"底仓**。iAlpha 8 ETF 月度再平衡、一致性风险度量（极速版）、股债波动平衡、国债固收+ 都能直接用。资金量大（千万级）的首选。

### 11.J 量化择时 / 指标 / 复现（13 个）

**核心**：**不是策略，是工具/指标**。用市场宽度/拥挤率/情绪/RSRS 决定仓位系数（0–1），叠加到任意子策略。

**逻辑**：
- 顶层是大盘择时（满仓/半仓/空仓），底层选股器可以叠任何策略。
- RSRS：阻力支撑斜率 z-score，情绪指数（CICSI、北向资金），C-VIX 中国版波动率，市场宽度（新高/新低比），牛熊指标（华泰）。
- 通常输出 0–1 仓位系数，叠加到子策略的"建议仓位"上。
- 实际效果：把回撤砍掉 30–50%，年化损失 5–10%。

**关键信号**：RSRS 斜率 z-score + 市场宽度 + 拥挤率 + 情绪指数分位 + 牛熊指标。

**挽救建议**：**任何主线策略都建议加一个择时模块**。jk2bt 已经有现成的实现，可以作为"灵魂模块"植入。

### 11.K 其他 / 实验 / 容量型（11 个 + 127 个 K_其他_通用）

**核心**：分散的实验性策略（遗传算法挖因子、强化学习、聚类、神经网络 pipeline）+ **大容量分散策略**（95 只小市值、200 只量化）。

**逻辑**：
- 容量型：用 95–200 只股票分散单股风险，逼近金元顺安元启、锐天中证 500 指增等产品形态。
- 实验型：遗传算法挖因子、强化学习 DQN、聚类分桶、神经网络端到端——可作为研究方向。
- 部分依赖手工标签（如韶华研究之二的 `follow_brain.csv`），不属于全自动策略。

**关键信号**：组合换手率 + 单股权重 + 跟踪误差（容量型）；回测 IC、AUC（实验型）。

**挽救建议**：实验性需自行评估；大容量版（95 只小市值）可直接用，是 A 类的**容量版替代**。

### 11.L 主观辅助 / 作业 / 实盘（4 个）

**核心**：作者本人**实盘在跑**的策略 + 主观辅助决策的混合策略（人工确认 + 程序下单）。

**逻辑**：
- 主观辅助形态识别：人工看 K 线确认形态 → 程序下单执行。
- 韶华系列：作者本人研究的方法论集合，含 14 个 jupyter 和 12 个 txt。
- 实盘分享：作者声明"已经在跑"的策略，通常带风控。

**关键信号**：人工确认 + 程序化风控（止损/仓位）。

**挽救建议**：**慎用**。需要看具体作者、具体方法论、与自己风格的匹配度。**不可盲信 "年化 X 倍" 的回测数字**。

### 13.3 11 个主策略逐项详评

#### 1. 小市值（Size Premium）

- **核心**：全 A 中筛最小 10-100 只，吃长期小盘溢价。
- **A 股证据**：A 股长期存在显著小盘溢价，但 2024-01 后被国九条部分抑制。
- **三项目证据**：

  - jqtest：`contrarian_smallcap_csi1000.py`、`high_return_csi1000.py`、`alpha_zoo_top3_csi1000.py`
  - analysis_v2：`factors/size_derived` 模块 + `factors/barra.py` (含 non_linear_size)
  - QuantGPT：HighYieldConfig (P1.6) 用 csi2000 + csi1000，**A 级因子率最高**
- **挽救建议**：用国九版本（4 只 + 银华日利空仓月份），或 95 只大容量版做分散。

#### 2. 价值/低估值（Value Premium）

- **核心**：低 PE / 低 PB / 低 PCF 的股票，长期估值修复。
- **A 股证据**：A 股 HML 因子长期显著（熊市更明显）。
- **三项目证据**：
  - jk2bt 聚宽 558：E 类 22 个（红利搬砖、价投、PEG、PE-PB）
  - jqtest：`b_group_fundamental.py`、`quality_value_buffett_csi500.py`、`hs300_orthogonal_factors.py`

  - QuantGPT：valuation(11因子) + financial(95因子) + 5 因子 PEG 组合
- **挽救建议**：完全跨周期，可直接跑。

#### 3. 动量/趋势（Momentum + Reversal）
